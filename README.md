# Responsive Check - 多分辨率响应式布局检查工具

自动在 6 种常见设备分辨率下对任意网页进行截图检查，分析响应式布局问题，生成自包含的可视化 HTML 报告。

## 核心功能

- **6 种设备自动截图**：iPhone SE (375×667)、iPhone 14 (390×844)、iPad Mini (768×1024)、iPad Pro (1024×1366)、笔记本 (1366×768)、桌面 (1920×1080)
- **智能滚动截图**：自动检测页面高度，逐屏滚动截取完整页面内容（每个分辨率最多 5 张）
- **问题标注框**：在有问题的截图上叠加红色标注框，精确圈出问题区域（导航溢出、广告遮挡、元素错位等）
- **自包含 HTML 报告**：所有截图 base64 内嵌，报告文件可独立打开分享
- **Lightbox 放大查看**：点击截图弹出大图，支持滚轮缩放（0.5x~5x）、双击复位、ESC 关闭
- **自动弹窗处理**：自动关闭广告弹窗、年龄验证、Cookie 同意等干扰元素

## 报告内容

1. 检查结果汇总表格（设备、分辨率、布局模式、评价、问题描述）
2. 各分辨率首屏截图卡片（带红色标注框）
3. 发现的问题与优化建议
4. 滚动截图详情（按设备折叠展示，有问题的带标注框）
